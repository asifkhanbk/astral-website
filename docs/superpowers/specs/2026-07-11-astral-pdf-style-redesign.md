Date: 2026-07-11

## Goal

Rework the Astral single-page portfolio so the header, hero, and footer feel much closer to the original PDF profile design language.

The user approved the generated concept direction:

- Strong royal/deep blue brand bands
- Larger, more intentional logo placement

1. Replace the tiny cropped header mark with a stronger PDF-style logo lockup.
2. Improve hero image quality with a premium pool image asset.

4. Rebuild footer/contact into a wave-shaped royal-blue panel over premium pool imagery.
5. Preserve real Astral contact details from the PDF.
6. Maintain responsive desktop and mobile layouts.
